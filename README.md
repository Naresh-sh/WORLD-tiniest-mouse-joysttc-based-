# 🕹️ Pico Joystick Mouse 🖱️

### ⚡ Turn your Raspberry Pi Pico into a Smooth Joystick-Controlled Mouse ⚡

---

## 🎯 Kya hai ye?

🔥 Ek simple, lightweight, aur super customizable **Joystick to USB Mouse** project 🔥

🎮 Analog joystick se cursor control karo
🖱️ Left click bhi joystick button se
⚙️ Fully tunable sensitivity
✨ Smooth curved movement — no jerky jumps

---

## 🚀 Features

✅ Smooth analog movement
✅ Adjustable **Sensitivity**
✅ Adjustable **Deadzone**
✅ Adjustable **Max Speed**
✅ Averaged readings — no jitter, no noise
✅ Squared/Cubed response curve — fine control 🎯
✅ Plug & Play USB Mouse 🔌

---

## 🛠️ Hardware

🧩 Raspberry Pi Pico
🕹️ Analog Joystick Module (X, Y, SW)
🔌 USB Cable

---

## ⚙️ Pin Setup

🟢 **X-axis** → GPIO 26
🔵 **Y-axis** → GPIO 27
🔴 **Switch** → GPIO 28

---

## 🎛️ Sensitivity Control

😴 **Low Sensitivity** = Chill, slow, precise movement
⚡ **High Sensitivity** = Fast, twitchy, gamer-mode 🎮

🔧 Sab kuch code ke top mein easily tune ho sakta hai:

```
DEADZONE
SENSITIVITY
MAX_SPEED
```

---

## 📦 Requirements

📚 Arduino IDE
🎯 Board: Raspberry Pi Pico
🧰 USB Stack: **Pico SDK** (default)
🖱️ Mouse.h library
